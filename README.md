# Digital Justice Hub: stakeholder demonstration

Clickable prototype of the Digital Justice Hub pilot for Project Expedite Justice, prepared by Synops Consulting LLC.

- Fictional training material only. Do not enter real case information.
- Everything runs in the browser; the server only serves `index.html`. Nothing a visitor types is sent to or stored on the server.
- Not the production platform. Production requires hosting in Ukraine, server-side access control and PEJ content approval.

Run locally: `node server.js`, then open http://localhost:3000.
